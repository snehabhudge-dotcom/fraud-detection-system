# Credit Card Fraud Detection System

## Project Overview
This project uses Machine Learning to identify potentially fraudulent credit card transactions.

## Objectives
- Detect fraudulent transactions.
- Compare different ML algorithms.
- Build an interactive web application.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Machine Learning Algorithms
1. Decision Tree Classifier
2. Random Forest Classifier
3. Gradient Boosting Classifier

## Dataset
Credit Card Fraud Detection Dataset from Kaggle.

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

The dataset contains transaction features and a target column named Class.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- PR-AUC
- Confusion Matrix

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Project Features
- Transaction prediction
- Fraud detection
- Model comparison dashboard
- Performance visualization

## Disclaimer
This project is developed for educational purposes only.
It is not intended for real banking decisions.
